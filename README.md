# RANI SLAYER — متجر إلكتروني

واجهة متجر عربية متجاوبة تعمل على الهاتف والكمبيوتر.

## النشر على GitHub Pages
1. ارفع `index.html` إلى جذر الفرع `main`.
2. افتح Settings → Pages.
3. اختر Deploy from a branch، ثم `main` و`/(root)` واحفظ.
4. الرابط المتوقع لهذا المستودع: https://alirqi.github.io/rani---slayer/

## الحالة والحدود
- جاهز: واجهة عربية متجاوبة، منتجات تجريبية، بحث وتصنيفات، سلة مشتريات، ونموذج طلب تجريبي.
- الطلبات تُحفظ في LocalStorage على جهاز العميل فقط؛ لا تُرسل إلى صاحب المتجر.
- غير جاهز للإنتاج: تسجيل الدخول، لوحة إدارة محمية، قاعدة البيانات، الدفع، الإشعارات، وتتبع الطلبات.
- يلزم إعداد Supabase مع Auth وقاعدة بيانات وسياسات RLS قبل استقبال طلبات حقيقية.
- لا تضع مفاتيح سرية مثل service_role في ملفات الواجهة.
- GitHub Pages يستضيف الواجهة الثابتة فقط ولا يشغّل Backend.
- المنتجات والأسعار أمثلة تجريبية ويجب استبدالها ببيانات المتجر الحقيقية.
